# Logo 来源

这些 SVG 由 models.dev 仓库的 provider logo 目录快照而来，或在 models.dev 没有专属图标时使用本仓库的中性 `default.svg` 占位图。每个 provider 的机器可读来源、映射关系和 `dedicated / mapped / fallback` 状态见 [`../models-dev-2026.json`](../models-dev-2026.json)。

models.dev 仓库代码采用 MIT 许可，但具体厂家图形可能受商标和品牌指南约束；本目录仅用于标识数据来源，不暗示厂商背书。正式对公众 CDN 发布前，应保留 models.dev 的许可声明并完成商标/再分发复核。SVG 被构建器限制为无脚本、无外部引用的静态文档。
